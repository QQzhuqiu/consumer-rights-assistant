# data —— 本地数据目录（内容不入库）

当前状态：**空目录，仅保留 `.gitkeep`**。

## 规则

1. `data/` 下的内容**默认不提交进 Git**（`.gitignore` 中 `/data/*` 全部忽略）。
   只有本说明文件和 `.gitkeep` 被显式白名单放行。
2. 这里用来存放：本地示例凭证、未来用户上传的图片、SQLite 数据库文件、
   临时抽取结果。这些内容可能包含真实个人信息，**一律不提交**。
3. 数据库文件（`*.db`、`*.sqlite`、`*.sqlite3` 及其 `-wal` / `-shm` / `-journal`
   附属文件）在任何位置都已在 `.gitignore` 中忽略。

## 何时可以提交演示样例

只有在同时满足以下条件时，才允许把样例数据放进仓库：

- [ ] 数据是**明确标注的合成数据**（虚构姓名、虚构商家、虚构金额），或已**脱敏**；
- [ ] 已由人工逐字段检查，不含真实姓名、手机号、地址、订单号、支付凭证号；
- [ ] 图片中不含人脸、二维码、条形码、余额等高敏感信息（如需要，做马赛克后另行存放）；
- [ ] 放在单独目录（例如 `data/samples/`），并在 `.gitignore` 末尾新增白名单规则；
- [ ] 在对应 commit message 中注明「合成数据 / 脱敏样例」。

> 目前尚未创建 `data/samples/`，也没有任何样例数据。
