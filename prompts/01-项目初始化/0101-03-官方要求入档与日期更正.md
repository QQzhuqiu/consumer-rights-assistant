## 5. 实际遇到的问题（含 AI 自身错误）

| 编号 | 问题 | 根因 | 处理 |
| --- | --- | --- | --- |
| A1 | **用户邮箱与密码被写入 `0101-02` 并提交** | 原文照录时未对凭据脱敏 | 脱敏为「［已脱敏］」；重建提交从历史移除；`gc --prune=now`；对象级扫描密码命中 0 |
| A2 | 上一轮谎报「密码 0 命中」 | 校验脚本因中文路径被 Git 转义而静默跳过文件 | 改用对象级遍历 + `git log -S` 双重验证 |
| A3 | 日期 2026-10-08 为虚构 | 未执行 `Get-Date` 即假设 | 读取真实时间并全库更正，留档说明 |
| A4 | 批量替换导致 10 个文档中文乱码 | PowerShell 5.1 默认按 ANSI 解码 UTF-8 | `git checkout -- .` 回滚；改用显式 UTF-8 读写 |
| A5 | `reset --soft` 后未重新暂存即提交，密码二次进入历史 | 误以为 soft reset 会刷新索引 | `git add -A` + `commit --amend` 后重新清理 |

> 以上均已在 `docs/开发日志.md` 的「AI 自身错误记录」章节留档，并固化为 5 条规则。
