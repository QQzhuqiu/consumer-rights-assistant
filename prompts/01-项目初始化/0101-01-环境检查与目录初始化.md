**环境层面的小障碍（诚实记录，属环境限制而非 Bug）**

| 编号 | 现象 | 影响 | 处理方式 |
| --- | --- | --- | --- |
| E1 | `Get-CimInstance Win32_OperatingSystem` 返回「拒绝访问」 | 无法用该方式获取系统名称 | 改用注册表 `CurrentVersion` 与 `[Environment]::OSVersion`，取得 Windows 10 Home China / 25H2 / 26200.8875 |

| E3 | `git config --global --list` 报 `unable to read config file` | 该用户尚无全局 git 配置文件 | 判定提交身份未配置，如实记录，不修改全局配置 |
| E4 | `git rev-parse` 输出混入 stderr 导致 PowerShell 报 NativeCommandError | 无 `.git` 目录时的正常报错 | 确认为「不在任何 Git 仓库内」的预期结果 |
