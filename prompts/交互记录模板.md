# 交互记录模板

> 使用方法：复制本文件到对应分类目录，重命名为
> `<阶段号><分类号>-<序号>-<主题>.md`，逐项填写。
> **没有发生的环节填写「未发生」，无法确认的填写「待补充」或「未验证」，不要留空、不要编造。**

---

## 0. 记录基本信息和目标

| 字段 | 内容 |
| --- | --- |
| 记录 ID | 例：`0101-01` |
| 实际时间 | `YYYY-MM-DD HH:MM`（本地时间，写实际发生时间，不写计划时间） |
| 所属阶段 | 例：阶段一 项目初始化 |
| 所属功能 | 例：环境检查 / 凭证识别 / 法规检索 |
| 本次目标 | 一句话说明这次交互要达成什么 |
| 明确不做的范围 | 例：不安装依赖、不调用 API |
| 使用的 AI 工具（展示名称） | 例：某桌面端 AI 编程助手（以界面实际显示为准） |
| 实际模型 ID | **未验证** / 已知则填写服务商返回的真实 ID；展示名称不等于模型 ID |
| 会话/对话标识 | 有则填（不含个人隐私），无则写「不可得」 |
| 材料性质 | ☐ 原始导出 ☐ 脱敏副本 ☐ 人工摘要 |

如果本文件是**脱敏副本**，必须在此写明：

- 脱敏范围：（例：删除本机绝对路径中的用户名、删除终端中的 key 前后缀、删除商家真实名称）
- 原始文件相对路径：（例：`evidence/ai-collaboration/raw/xxx.json`，本地保存不提交）
- 脱敏执行人 / 时间：
