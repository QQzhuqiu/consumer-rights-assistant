## 约定

- 脚本只能从本地环境变量读取密钥，**不得**把密钥作为命令行参数或写进日志。
- 任何会调用付费 API 的脚本必须内置单次/累计费用保护，并在运行时打印实际用量。
- 脚本产生的临时产物写入 `data/` 或系统临时目录，且已被 `.gitignore` 覆盖。
- 探针脚本按预设规则输出限定字段，**不打印密钥、请求头、完整地址或响应正文**；
  该约束仅指脚本行为，**不构成对脚本的独立安全审计结论**。
- 当前已创建的脚本：`api-probe.mjs`（一次性探针，**不是产品业务代码**）。
