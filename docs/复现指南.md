## 1. 获取仓库

从用户可访问的 GitHub 远端克隆仓库：

```powershell
git clone <GitHub 仓库地址> "凭证明白-AI消费权益助手"
cd "凭证明白-AI消费权益助手"
git status --short --branch
```

> 仓库 Public 状态或评审访问权限需用户在 GitHub 网页确认。若无法访问远端，请由用户提供具备访问权限的仓库地址；本指南不假定仓库公开。

也可在已有本地克隆中进入项目根目录。运行以下检查命令只能确认当前检出状态，不能代替完整复现或 10 分钟计时。


具体机器配置与本次复现环境版本：**待用户实测并记录**。

## 3. 安装依赖

在项目根目录执行：

```powershell
npm ci
```

`npm ci` 根据仓库中的 `package-lock.json` 安装依赖。此处提供可执行命令，不表示本指南已在干净环境验证安装成功；真实执行结果待复现者记录。

## 4. 环境变量与安全边界

只运行 UI 和本地 mock 流程不需要模型密钥，也不需要创建 `.env.local`。

当前产品仅在服务端读取 `DEEPSEEK_API_KEY`。若复现者明确要测试真实 DeepSeek 摘要，可先在本机复制模板并仅在被忽略的 `.env.local` 中填入本人密钥：

```powershell
Copy-Item .env.example .env.local
```

不要把真实密钥写入 `.env.example`、README、日志、截图或提交。只有用户在 AI 确认弹窗点击“确认发送”后才会请求真实服务；这可能产生费用。未配置 `DEEPSEEK_API_KEY` 时，真实 DeepSeek 调用不能完成；界面可能显示明确标记的本地整理回退结果，该结果不代表 API 调用成功。

页面不做自动个人信息识别或脱敏。API 场景的具体数据保留期限和退出机制仍未核实；不要作不留存或不用于模型训练的承诺。只做 UI 复现时不要触发真实模型请求。

这是项目已有的 npm scripts。此指南没有声称这些命令已在干净复现环境成功；逐次结果应由复现者如实填写。

## 6. 启动

开发模式：

```powershell
npm run dev
```

按终端提示在本机浏览器打开 Next.js 开发服务器地址。停止服务器可在对应终端按 `Ctrl+C`。

可选生产模式（先成功完成 `npm run build`）：

```powershell
npm start
```

以上为启动命令，不代表已完成当前版本的干净环境复现。当前界面验收结论来自用户报告；本指南尚无独立复现者记录。

## 7. 建议检查范围

只做 UI 验收时，可由复现者检查：

- 珍珠/贝壳入口能进入四步：凭证、字段核对、事实陈述、整理结果；
- 工作区返回入口按钮和无弹窗时 Escape 返回行为；
- AI 确认弹窗打开、取消和弹窗内 Escape；不点击“确认发送”，避免真实请求；
- 入口与工作区切换后内存状态保留，刷新后按设计清空；
- 页面不出现横向溢出，桌面与窄屏布局可用。

这些项目是建议的复现检查清单，不是本文件声称已执行的测试结果。
