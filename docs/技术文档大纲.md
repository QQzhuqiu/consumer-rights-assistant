## 统一的写作规则

1. **状态标记**：每个功能描述前加状态（已验证 / 待验证 / 未实现）。
2. **数字必须有出处**：费用、耗时、命中率、测试通过率都要能对应到日志或截图。
3. **引用法规**：写出名称、条号、发布机关、官方 URL、访问日期、当前有效状态。
   无法核实的不写。
4. **区分「设计」与「实现」**：设计章节用「计划/将」，实现章节用过去时并附证据。
5. **不写营销式形容词**，不使用「业界领先」「全面覆盖」等不可验证表述。
6. **截图脱敏**：所有截图使用合成数据，且经过 `evidence/screenshots/README.md` 的检查清单。
