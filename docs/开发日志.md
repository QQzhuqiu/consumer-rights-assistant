### 从上述错误中固化的规则

1. **凭据一律不进入任何记录**：即使是「用户原始 Prompt 原文」，也必须先做凭据脱敏再落盘。
   脱敏不是篡改，但**必须在文首声明脱敏范围**，不得让脱敏副本冒充原始记录。
2. **「未命中」必须可证明**：检索敏感串时，路径解析失败要报错，不能静默跳过；
   至少用两种独立方法（工作区全文检索 + `git log -S` + 对象级遍历）交叉验证。
3. **时间、版本、哈希一律取自系统或命令输出**，不得凭印象填写。
4. **批量改文件前先备份/确认可回滚**（本项目依靠 Git 即可回滚，故先提交再批量改）。
5. **含凭据的提交若尚未推送，应重建历史；若已推送，则必须改密并接受历史留存。**
