## 8. 需要用户处理的最小事项

在项目根目录执行一次即可（**由用户本人执行**，Agent 不代为填写身份）：

```powershell
# 仅对本仓库设置提交身份（推荐，不污染全局）
git config user.name "你的提交用名字"
git config user.email "你的提交用邮箱或 GitHub noreply 邮箱"

# 或：设置为全局（影响本机其他仓库，请自行判断）
# git config --global user.name "..."
# git config --global user.email "..."

# 配置后验证（只显示是否已配置，不打印邮箱全文）
git config --get user.name; git config --get user.email
```

配置完成后，本阶段可补做一次初始化提交：

```powershell
git add <逐条列出的文件>
git commit -m "chore: initialize project documentation and evidence workflow"
```

> 本文件不记录私人邮箱。验证时用 `git config --get user.email` 自行确认即可。
