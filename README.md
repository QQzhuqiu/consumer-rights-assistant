# 凭证明白 · AI 消费权益助手

> 消费纠纷事实整理与证据准备工具。

本项目帮助消费者把已有凭证信息、个人陈述和证据线索整理成更清晰的事实材料。当前交付重点是本地输入整理、证据准备和一项受控的文本事实摘要，不是法律判断产品。

- GitHub 仓库：[QQzhuqiu/consumer-rights-assistant](https://github.com/QQzhuqiu/consumer-rights-assistant)
- 仓库 Public 状态：由用户在 GitHub 网页确认；本 README 不声称代理在线核验
- 当前最新已推送提交：`4b213ea docs: document pearl flow UI and workspace behavior`

## 当前产品能力

当前版本已实现：

- 珍珠/贝壳主题的流程入口；
- “凭证”“字段核对”“事实陈述”“整理结果”四步工作区；
- 浏览器本地凭证文件预览；
- 基于固定合成样例的字段核对、确认、编辑和未知标记；
- 明确标记为 `mock` 的本地识别演示；
- 用户事实陈述和处理诉求输入；
- 离线整理准备状态与缺口提示；
- 事实时间线；
- 材料记录清单；
- 用户确认后调用官方 DeepSeek 文本接口生成事实整理摘要；
- 从工作区返回流程入口、Escape 返回，以及页面切换时保留内存状态。

当前流程中的字段、时间线和材料清单均来自固定样例或用户在页面填写的内容。它们不新增事实、不做因果推断，也不写入数据库。

## 当前不支持的能力

以下能力当前未实现，不能据此项目做出相关承诺：

- 凭证图片的真实视觉模型识别；
- 凭证图片上传到服务器；
- 法规检索、法规查证或已核验的法规语料检索；
- 商家违法、责任归属、退款、赔偿或其他权益判断；
- 投诉、诉讼、维权或成功率建议；
- 投诉材料或其他法律材料正文自动生成；
- 数据库、历史记录和持久化保存；
- 真实用户调研结论。

本项目输出仅供事实整理参考，不构成法律意见、事实认证、权益判断或胜诉/赔偿承诺。

## 使用流程

1. 从流程入口进入四步工作区。
2. 在“凭证”步骤选择本地文件并查看浏览器本地预览；当前不会把文件上传到服务器。
3. 在“字段核对”步骤查看固定合成样例字段，或进行确认、编辑和未知标记；本地 mock 结果会明确标识来源。
4. 在“事实陈述”步骤填写用户掌握的事实、处理诉求和证据线索。
5. 在“整理结果”步骤查看离线整理准备、事实时间线、材料记录清单和 AI 摘要入口。
6. AI 摘要发送前会展示确认弹窗。只有用户点击“确认发送”后，页面才会向同源服务端摘要路由发起请求。

入口与工作区通过页面内状态切换，切换时保留当前内存状态；刷新页面会按当前实现清空内存状态。

## 技术栈与架构

- Next.js 15 App Router
- React 19
- TypeScript 5
- Tailwind CSS 4
- 依赖声明见 `package.json`，锁定版本见 `package-lock.json`

主要边界：

- 客户端负责流程入口、工作区交互、本地预览和本地整理展示；
- `/api/extract` 是本地 mock 数据接口，不是真实视觉模型接口；
- `/api/summarize` 只接受服务端摘要请求，并在服务端读取 `DEEPSEEK_API_KEY`；
- 客户端不读取环境变量、不接触密钥、不直连上游模型；
- 时间线和材料清单是纯本地逻辑，不使用数据库、网络或持久化；
- 没有引入 SQLite、Prisma、better-sqlite3、Vitest 或 Playwright。

## 环境变量

当前产品只读取服务端环境变量 `DEEPSEEK_API_KEY`，读取位置为 `src/app/api/summarize/route.ts`。

`.env.example` 是空模板，仅包含变量名：

```text
DEEPSEEK_API_KEY=
```

如需在本机测试真实 DeepSeek 摘要，可复制模板为 `.env.local`，再由用户自行填写密钥。`.env.local` 已被 `.gitignore` 忽略，不得提交真实密钥。不要使用 `NEXT_PUBLIC_` 前缀，因为该前缀会将变量暴露到浏览器端。

`AI_API_BASE_URL`、`AI_API_KEY`、`AI_TEXT_MODEL`、`AI_VISION_MODEL` 是旧的拟定配置，不属于当前产品所需配置。

未配置 `DEEPSEEK_API_KEY` 时，服务端不会完成真实 DeepSeek 调用，而是返回明确标识的本地整理结果；本地回退不等于真实 API 成功。

## AI 与隐私边界

- 摘要请求只在用户于确认弹窗点击“确认发送”后发起；
- 发送内容由页面已有的已确认字段、用户陈述、事实时间线和材料清单等少量文本整理而来，具体范围以当前请求校验代码为准；
- 摘要只做事实整理，不是事实认证、法律意见或权益判断；
- 页面不会自动识别或脱敏个人信息，用户应在发送前自行检查；
- DeepSeek API 场景的数据保留期限和退出机制尚未核实；
- 本项目不承诺数据“不留存”或“不用于训练”；
- 不要在仓库、日志、截图、录屏或文档中写入真实密钥和真实消费凭证。
