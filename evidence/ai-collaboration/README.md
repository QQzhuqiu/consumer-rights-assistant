# ai-collaboration —— AI 协作证据索引（主副本）

这里存放**按核心功能组织的证据索引**，是整个项目「AI 协作证据」的唯一定位入口。

## 规则速览

- 索引是纯文本 Markdown，**可以提交**。
- 索引里只写**相对路径**，不复制 Prompt 正文、不复制截图内容、不复制原始对话。
  Prompt 正文的主副本在 `prompts/`，媒体素材的主副本在本地磁盘。
- 每一条索引记录必须能回答：这条证据证明了什么、对应哪个 Git 提交、对应哪个 Prompt 记录。
- 不存在的证据写「未产生」，不写占位赞美词。

## 单个核心功能索引的必备字段

每个功能索引文件至少包含：

1. **功能目标与边界**（一句话说清做什么、不做什么）
2. **迭代链**：按版本列出「Prompt 记录 ID → 主要变更 → Git 提交哈希 → 截图/录屏 → 测试与检查 → 人工结论」
3. **真实 Bug 清单**：只写实际发生过的，含现象、定位过程、修复方式、回归检查
4. **未完成与风险**
5. **素材位置**：每一类素材写清楚是原始、脱敏副本还是人工摘要

## 与 prompts/ 的分工

| 内容 | 主副本位置 |
| --- | --- |
| Prompt 原文、AI 回复原文（脱敏后） | `prompts/` |
| 该 Prompt 的索引与关联关系 | `evidence/ai-collaboration/` |
| 截图 / 录屏 / 成片 | `evidence/screenshots/`、`recordings/`、`demo/`（原始素材本地保存） |

同一份内容只保留一个主副本，其余位置用相对路径链接，避免两处维护导致内容漂移。
