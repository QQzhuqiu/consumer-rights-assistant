## 录制计划（在真正开始前执行）

详见 [开发与AI协作规范 · 录屏安排](../../docs/开发与AI协作规范.md#录屏安排)。
要点：

1. 在**初始化收尾的补充镜头**与**三个核心功能开发开始前**启动录屏。
2. 录屏必须包含真实的 Prompt 输入、AI 修改代码、人工反馈、问题排查与检查结果。
3. 不制造故障、不摆拍、不补录「像发生过」的流程；如果过程中出问题，如实保留。
4. 不要求每段固定时长，按实际开发节奏录制，后期剪辑。
