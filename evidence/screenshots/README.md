## 存放规则

| 内容 | 处理方式 |
| --- | --- |
| 原始截图（含完整界面/终端） | 存本地，文件名含 `raw` 或 `原始`，**不提交** |
| 脱敏后的最终截图 | 文件名含 `-redacted`，需在 `evidence/README.md` 规则下单独加白名单后才可提交 |

- [ ] 无 API Key、令牌、Cookie、请求头
